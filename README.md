# Mission Portfolio

Portfolio tugas Full-Stack Development milik Fadlan Khalqi. Website ini mendokumentasikan Mission 2–8, mulai dari Git, frontend, JavaScript, database, React, hingga REST API.

## Membuka portfolio

Buka `index.html` langsung di browser. Website dibuat dengan HTML, CSS, dan JavaScript tanpa proses instalasi tambahan.

## Isi portfolio

- Mission 2: Studi kasus Git merge conflict
- Mission 3: UI responsif VideoBelajar
- Mission 4: TaskFlow dengan JavaScript dan localStorage
- Mission 5: Perancangan database EduCourse
- Mission 6: Course API dengan Express dan MySQL
- Mission 7: Aplikasi React CHILL dan integrasi MockAPI
- Mission 8: EduCourse API dengan autentikasi dan upload
