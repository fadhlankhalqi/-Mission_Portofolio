# Belajar Full-Stack Lewat 7 Mission

Selama mengikuti pembelajaran Full-Stack Development, saya mengerjakan Mission 2–8 sebagai latihan untuk memahami bagaimana sebuah aplikasi web dibangun secara bertahap.

Perjalanannya dimulai dari menyelesaikan Git merge conflict, membuat tampilan responsif dengan HTML dan CSS, menambahkan interaksi JavaScript dan localStorage, merancang database relasional, membangun REST API, mengintegrasikan React dengan MockAPI, hingga menambahkan autentikasi dan upload pada backend.

Setiap mission memberi tantangan yang berbeda. Dari proses tersebut, saya belajar bahwa memahami kesalahan, mencoba kembali, dan mendokumentasikan progres merupakan bagian penting dari pembelajaran.

Portfolio ini bukan kumpulan hasil yang sempurna, tetapi catatan perkembangan saya selama belajar membuat aplikasi dari frontend hingga backend.

Terus belajar, satu mission pada satu waktu.
